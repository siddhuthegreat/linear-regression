# Linear Regression from Scratch

This project implements Linear Regression from scratch using Python without relying on machine learning libraries. It demonstrates how to calculate the best-fit line using mathematical formulas and visualize the results.

## Features
- Implements Linear Regression without using ML frameworks
- Calculates slope and intercept using statistical formulas
- Predicts output values for given inputs
- Visualizes the regression line and data points

## Libraries Used
- NumPy
- Matplotlib

## Usage

Clone the repository:

git clone https://github.com/siddhuthegreat/linear-regression.git

Navigate to the project folder:

cd linear-regression

Run the program:

python main.py

## Output
- Displays the regression line along with the data points in a graph.
- Predicts values based on the linear regression model.
